# GaitGuard brand assets

- `gaitguard-logo-1024.png`: app icon, 1024 px, dark background (what is on the phone and Watch)
- `gaitguard-logo.svg`: same icon as a vector, dark background
- `gaitguard-mark.svg`: the mark only, transparent background (use on dark sections of a site)

Colours: char `#12100E`, ember `#FF7A4D`, brass `#E8C9A0`, ash `#A39A90`, soot `#6B635B`, bone `#F4EEE6`
Type: Fraunces (display numerals and headlines), DM Sans (labels). The app itself uses the system serif and sans.
Name: GaitGuard (no "AI").
